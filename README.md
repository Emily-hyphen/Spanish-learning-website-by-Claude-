# Español 西班牙文學習網站

給華語母語者的西班牙文自學網站（A1 → B1），所有內容附中文與 English 對照，含發音按鈕與互動小測驗。

- 線上網址：`[https://emily-hyphen.github.io/Spanish-learning-website-by-Claude-](https://emily-hyphen.github.io/Spanish-learning-website-by-Claude-/)/`
- 專案規則請見 [`CLAUDE.md`](CLAUDE.md)
- 本機預覽：`python3 -m http.server`，然後開啟 http://localhost:8000
- 新增課程：複製 `lessons/_template.html`，並更新 `data/lessons.json`
