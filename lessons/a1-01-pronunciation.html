發音與字母 Pronunciation & the Alphabet

學習目標

  • 學完後你可以唸出 5 個母音 a、e、i、o、u。
  • 學完後你可以說出 27 個字母的名稱，並用西班牙文字母拼出自己的名字。
  • 學完後你可以判斷 h、j、ñ、ll、rr、qu、gue／gui 等特殊拼法的唸法。
  • 學完後你可以看到一個字，就知道重音在哪個音節。
  • 學完後你可以跟著唸 hola、gracias、por favor 等最基本的用語。
西班牙文「所見即所唸」：拼寫和發音高度對應，只要學會本課的規則，幾乎每個字都能唸出來。

文法重點

1. 五個母音

西班牙文只有 5 個母音，每個永遠只有一種唸法（和華語類似，不像英文會變來變去）。

母音近似華語例字中文English
aㄚcasa 房子house
eㄝmesa 桌子table
iㄧsí 是yes
oㄛsolo 只有；獨自only; alone
uㄨuno 一one
華語有聲調，西班牙文沒有；但句子有「語調」，疑問句尾音上揚。以上近似音只是幫助你抓大概，請多聽 🔊 模仿。

3. 特殊發音規則

拼法唸法例字中文English
h不發音hola 哈囉hello
j、ge、gi像較重的華語ㄏ（喉嚨摩擦）jamón / gente 火腿 / 人們ham / people
ga、go、gu像ㄍgato 貓cat
gue、gui像ㄍ，u 不發音guitarra 吉他guitar
ñ近似「ㄋ一」niño 男孩boy
ll、y近似 y（如 yes）calle 街道street
rr、字首 r彈舌perro 狗dog
qu像ㄎ（k），u 不發音queso 起司cheese
c + a、o、u像ㄎ（k）casa 房子house
c + e、i；z拉美像 s；西班牙像 thcena / zapato 晚餐 / 鞋子dinner / shoe
b、v發音相同（輕輕的 b）vino / barco 葡萄酒 / 船wine / boat
c + e／i 與 z 的唸法，西班牙和拉丁美洲不同：西班牙是類似英文 think 的 th，拉丁美洲唸 s。兩種都能被理解，選一種一致地用就好。

規則例字中文English
