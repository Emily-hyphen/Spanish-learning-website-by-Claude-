名詞的性與數、冠詞 Gender, Number & Articles

學習目標

  • 學完後你可以判斷常見名詞是陽性還是陰性（看結尾：-o、-a、-ción、-dad 等）。
  • 學完後你可以選對定冠詞 el、la、los、las。
  • 學完後你可以選對不定冠詞 un、una、unos、unas。
  • 學完後你可以把名詞變成複數（+ -s、+ -es、-z → -ces）。
  • 學完後你可以把陽性的人物名詞變成陰性，例如 niño → niña。
名詞的性別只是語法分類，不代表物品「有性別」，la mesa 不是說桌子是女性。有些字因性別不同而意思不同，例如 el capital（資金）與 la capital（首都）。

文法重點

1. 名詞有性別

西班牙文的每個名詞都是陽性（masculine）或陰性（feminine），連桌子、房子也不例外。華語沒有這個概念，所以要把冠詞當作名詞的一部分來記：el libro、la casa。

2. 怎麼判斷性別？看結尾

結尾性別例字中文English
-o通常陽性el libro el niño 書 / 男孩book / boy
-a通常陰性la casa la mesa 房子 / 桌子house / table
-ma通常陽性（希臘語源）el problema el programa 問題 / 程式；節目problem / program
-ción、-sión通常陰性la canción la estación 歌曲 / 車站song / station
-dad、-tad通常陰性la ciudad la universidad 城市 / 大學city / university
-e 或子音沒有規則，要背el coche la noche el hombre la mujer 汽車 / 夜晚 / 男人 / 女人car / night / man / woman
例外要特別記el día la mano 天 / 手day / hand
這些是「通常」成立的規則，不是百分之百。遇到沒把握的字，查字典並連冠詞一起背。

3. 人物名詞：陽性變陰性

陽性陰性中文English
el niño la niña 男孩 → 女孩boy → girl
el amigo la amiga 朋友（男 → 女）friend (m → f)
el profesor la profesora 老師（男 → 女）teacher (m → f)
el estudiante la estudiante 學生（形式不變，只換冠詞）student (same form, only the article changes)
-o 結尾換成 -a；子音結尾通常加 -a（profesor → profesora）；-e 或 -ista 結尾的字，陽性陰性同形，只換冠詞。

4. 冠詞：定冠詞與不定冠詞

冠詞要和名詞的性、數一致。定冠詞指「特定的」（the），不定冠詞指「不特定的」（a／an／some）。

陽性單數陰性單數陽性複數陰性複數
定冠詞 theel la los las
不定冠詞 a / someun una unos unas
句子中文English
el libro 那本書（特定）the book
un libro 一本書（不特定）a book
las casas 那些房子the houses
unas casas 一些房子some houses

5. 複數

單數複數規則中文English
el libro los libros 母音結尾 + -s書book(s)
la casa las casas 母音結尾 + -s房子house(s)
la ciudad las ciudades 子音結尾 + -es城市city / cities
la mujer las mujeres 子音結尾 + -es女人woman / women
el lápiz los lápices -z 改成 -ces鉛筆pencil(s)
la canción las canciones + -es，重音符號消失歌曲song(s)
冠詞和名詞都要一起變複數：el libro → los libros。los amigos 可以指全是男生，也可以指男女混合的一群人。
